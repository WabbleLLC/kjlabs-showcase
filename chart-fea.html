Step by step

  1. Bring in a part from Onshape, STEP or STL and choose a material.
  2. Place supports and loads: the quick axis band, or real CAD faces and round load patches for precision.
  3. Preview node counts so a bad support or load is caught before solving.
  4. Mesh with Gmsh and solve with CalculiX, headless.
  5. Check the solver log. A converged run produces a rendered stress plot and a saved example. A failed run sends you back to fix supports, mesh or material based on what the log says.

Why it is built this way

The rule is to read the log and never guess. A clean exit code alone isn't trusted. The pipeline checks convergence and checks that the physically expected fields are actually there.
